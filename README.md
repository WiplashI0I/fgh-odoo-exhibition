# FGH Odoo Exhibition

A public visual prototype for the Fusion Group Odoo handover discussion.

> **Visual prototype only.** This website is not connected to Odoo, employee data, user accounts, or live workflows. Every visible name, goal, task, review, feedback, recognition item, status, percentage and date is fictional and illustrative.

This repository contains only the static Exhibition artifact supplied for visual review. It does **not** contain Performance/Odoo source code, LMS source code, credentials, real employee information, or Confidential 360 material.

Future changes are added only after visual approval in the FGH Odoo handover programme.
